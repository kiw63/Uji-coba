RUANG PENYIMPANAN

Video terenkripsi di penyimpanan browser

Setelah upload, isi video/ZIP dan metadata dienkripsi sebelum masuk database browser. Salinan VaultBox terpisah dari file asli. Kapasitas tetap mengikuti kuota browser dan ruang kosong HP.

Untuk file besar, gunakan penyimpanan browser dan cadangkan media secara terpisah.
Penting: menanam video 3–5 GB ke dalam satu file HTML biasanya tidak realistis di HP karena encoding menambah ukuran sekitar sepertiga dan browser harus memuat data sangat besar ke memori. Upload langsung ke penyimpanan browser bisa menangani file besar jika kuota browser mengizinkan; kami tidak bisa menjamin angka 3–5 GB pada setiap HP.
